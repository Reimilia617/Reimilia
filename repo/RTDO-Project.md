# rtdo — Root Task Do：交互式、环境自适应的提权工具（替代 sudo）
#
# 项目仓库根目录的 Reimilia_Setup/ 里提供了两种安装方式：
#   Build  —— 源码编译（默认，不依赖是否发布过产物）
#   Binary —— 预编译二进制（需要 Release 里有 rtdo-<arch>-linux 等产物）
#
# 安装需要 root，Reimilia 会在需要时调用 sudo / sudo-force / su 提权。
# 文件名（去掉 .md）就是 Reimilia 界面上显示的项目名。
